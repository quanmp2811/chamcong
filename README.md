# Attendance Management System

Web application for employee attendance management built with Node.js, Express.js and MongoDB.

## Demo

Live Demo: https://chamcongjdd.io.vn/

## Features

- Employee attendance management
- Admin dashboard
- User authentication
- Google Login Authentication
- RESTful API
- Attendance history tracking
- Responsive interface
- MongoDB database integration

## Tech Stack

### Frontend

### Backend
- Node.js
- Express.js

### Database

## Installation

Clone project:

```bash
git clone https://github.com/quanmp2811/chamcong.git
```

Move to project folder:

```bash
cd chamcong
```

Install dependencies:

```bash
npm install
```

Create `.env` file:

```env
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
GOOGLE_CLIENT_ID=your_google_client_id
```

Run project:

```bash
npm start
```
